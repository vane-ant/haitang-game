# 🐢 海龟汤 · 身份局（网页版）

根据「海龟汤身份局」规则制作的线上多人游戏。竖屏聊天室 UI，零依赖 Node 后端，手机浏览器直接玩。

## ✨ 功能

- 🏠 **房间系统**：创建 4 位房间码，好友输入即可加入（上限 5 人）
- 👑 **主持人 = 房主**：主持人控制台可分配身份、回答提问、补充汤面、执行清空/转让、结束判定
- 💬 **聊天室 UI**：聊天 / 提问（扣次数）双模式，提问自动进主持人待答队列
- 🎭 **身份机制**：1 侦探 / 3 无辜者 / 1 杀手，身份秘密分配，只有本人可见
- 🔢 **次数系统**：总次数 T 开局公布，每人 T÷5 向下取整，次数保密、用完出局
- 📜 **汤面补充**：主持人可随时发布公开补充（可藏杀手暗号）
- 🔪 **杀手清空**：房主代执行清空任意玩家全部次数（2 次）
- 🕵️ **侦探转让**：房主操作侦探身份转让（不公开）

## 🚀 本地运行

```bash
# 需要 Node.js 18+（无需任何 npm 包）
node server.js
# 访问 http://localhost:3000
```

**局域网联机**：手机和电脑连同一 WiFi，手机浏览器访问 `http://<电脑IP>:3000`。

## 🌍 部署到公网（好友异地玩）—— Zeabur 免费方案

项目已内置 `zeabur.json` 配置，**零改造**直接部署：

1. 注册 [zeabur.com](https://zeabur.com)（支持 GitHub 登录，国内可直连）
2. 新建项目 → **部署你的代码** → 导入 GitHub 仓库 `haitang-game`
3. 系统自动识别 Node.js 并执行 `node server.js`（`zeabur.json` 已配好）
4. 部署完成自动分配免费域名 `https://xxx.zeabur.app`，**大陆可直接访问**
5. 把网址发给好友，随时开玩

> 💰 免费额度：每月赠送 $5 用量，低流量聊天室基本够用；用完按量计费（几毛钱级），可在后台设置用量限额。
> ⚠️ 免费额度域名闲置会休眠，首次访问等几秒唤醒。

### 其他平台备选

- **Render**：`node server.js` 即可，但国内 IP 可能要求绑卡
- **内网穿透（natapp 等）**：本地 `node server.js` + 免费隧道，电脑需常开
- **Glitch**：import 仓库即跑，但国内访问不稳定

## 🎮 玩法速览

1. 房主建房 → 好友输房间号加入（最多 5 人）
2. 房主在控制台填好 **汤面 + 汤底 + 总次数 T**，点击开始
3. 房主秘密分配身份（侦探×1 / 无辜者×3 / 杀手×1）
4. 玩家用"提问"模式问"是/否"问题（扣 1 次），房主在控制台点"是/否/无关"回答
5. 每轮房主可发布**公开补充**汤面内容（可含杀手专属暗号）
6. 杀手可请房主执行**清空**（2 次）；侦探可被房主**转让**给任意玩家
7. 解出汤底（≥90% 可申请立即结束）或次数耗尽 → 房主结束游戏、公布身份

## 🔒 说明

- 身份、次数通过服务端权威管理，客户端无法篡改
- 次数保密：玩家只能看到自己的剩余次数
- 消息持久化在内存中，服务器重启即清空
